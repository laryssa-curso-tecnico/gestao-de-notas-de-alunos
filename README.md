# Gestão de Notas de Alunos

A aplicação permite cadastrar alunos e suas notas, facilitando o acompanhamento e a organização do desempenho dos estudantes.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
